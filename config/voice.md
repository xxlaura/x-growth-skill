# Voice Profile

## Who I Sound Like
The engineer who built the product is tweeting directly. Specific, confident, no marketing department in between. When someone reads a post, they should think: "This account knows things others don't and respects my time."

## Account Type
Brand

Anti-slop strategy: **Specificity + Insider Knowledge + Product Confidence**
- Replace adjectives with numbers
- Show insider data only the team would have
- Confident statements, not hype
- Let the product demo speak
- Technical precision IS anti-slop
- Strategic restraint — don't oversell

## Tone
### Always
- Confident — state facts, don't hype
- Precise — specific numbers, specific capabilities
- Technical — speak developer language naturally
- Practical — focus on what it does, not what it "enables"
- Restrained — let the reader draw conclusions

### Never
- Hype — no "revolutionary", "game-changing", "incredible"
- Vague — no "powerful", "advanced", "seamless" without numbers
- Corporate — no "we are excited to", "we are proud to"
- Desperate — no "don't miss out", "limited time only!"
- Sycophantic — no "thank you to our amazing community"

## Sentence Rhythm
- Average length: Medium. Mix short punchy sentences with technical detail.
- Pacing: Measured. Not breathless, not slow.
- Paragraph style: Prose for context, bullets (→) for capabilities, dashes for asides.
- Avoid: Perfect parallel structure (✅✅✅), numbered lists for features, emoji as bullets.

## Hook Patterns
### Use
- **Data hook**: Lead with a specific number. "23ms p99 latency." "$0.018 per 1K tokens."
- **Product voice**: State it like a changelog. "Qwen3.7-Plus. Live on Model Studio."
- **Before/after**: "Before: 3-hour pipeline. After: 45 seconds."
- **Insider hook**: "Tested on 12,000 production workloads before launch."
- **Contrarian**: "Most developers are overpaying for AI APIs."

### Avoid
- "Introducing..." — slop marker #1
- "We're excited to announce..." — corporate slop
- "Meet [product]" — overused template
- "The future of [X] is here" — hype slop
- Question hooks (save for personal accounts)

## How I Open
Confident statement about what's new or what's possible. Backed by a number, a demo, or an insider detail within the first 2 lines.

Never open with: "Introducing", "We're thrilled", "Excited to share", "Meet", emoji-first, "🚀"

## How I Close
Clean, direct CTA. One line. No exclamation marks.

- "Available now via API →"
- "Try it → [link]"
- "→ [link]"

Never close with: "Don't miss this!", "Start your journey today!", "Join thousands of developers!", "Let us know what you think! 🙏"

## Signature Elements
- Arrow notation for capabilities: "→ Vision input → Reasoning → Code execution"
- Em dash for asides: "One API — that's it"
- Periods over exclamation marks
- Specific version numbers: "Qwen3.7-Plus" not "our latest model"
- Specific pricing: "$0.018 per 1K tokens" not "cost-effective"
- Specific dates: "20% off through July 2" not "limited time"

## What This Voice Never Does
1. Use vague adjectives without backing them up with numbers
2. Use exclamation marks (save for rare, genuine excitement)
3. Start a post with "Introducing" or "We're excited to"
4. Use the ✅✅✅ parallel bullet structure
5. Make claims without data, demo, or insider knowledge to back them up
6. Post more than one topic per tweet (one post = one message)
7. Use engagement bait ("Like if you agree", "RT this")
