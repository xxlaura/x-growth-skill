# Content Types: Templates and Examples

## 8 Core Content Types (Ranked by Algorithm Value)

### 1. Demo Video (30s-2min)
**Algorithm advantage**: VQV + dwell + share + profile_click
**Frequency**: Daily (1 per day)
**Format**: Video

**Structure:**
- [0:00-0:03] Hook: "Watch me build X in 60 seconds"
- [0:03-0:15] Setup: Show the problem/context
- [0:15-0:45] Demo: Actual product demonstration
- [0:45-0:55] Result: Show the outcome
- [0:55-1:00] CTA: "Try it → link in bio"

**Caption template:**
```
Built [thing] in [time] using Model Studio 🤯

[1-line explanation of what was built]

No infra, no setup, just API calls.

Try it yourself → [link]
```

**Example:**
```
Built a video summarizer in 90 seconds using Model Studio 🤯

Sent it a 10-minute YouTube video, got back a 30-second summary with key timestamps.

No infra, no setup, just one API call.

Try it → link in bio
```

## Content Mix Formula

**Weekly distribution (for 14-21 posts/week):**

| Content Type | Posts/Week | Percentage |
|--------------|------------|------------|
| Demo Video | 5-7 | 33% |
| Benchmark/Comparison | 2-3 | 14% |
| Use Case/Before-After | 3 | 14% |
| Open Source Spotlight | 2 | 10% |
| Promo/Offer | 1 | 5% |
| Giveaway | 1 | 5% |
| Meme | 2-3 | 14% |
| Technical Deep Dive | 1 | 5% |

**Daily distribution (2-3 posts/day):**

| Time | Content Type | Rationale |
|------|--------------|-----------|
| 9-10 AM | Demo Video or Benchmark | Developers starting work day |
| 1-2 PM | Use Case or Open Source | Afternoon browsing |
| 6-7 PM | Meme or Giveaway | Evening casual scrolling |

## Content Quality Checklist

Every post must:

- [ ] Have a strong hook (first line grabs attention)
- [ ] Deliver clear value (educational, entertaining, or useful)
- [ ] Include a CTA (reply, share, follow)
- [ ] Pass anti-slop check (humanized, imperfect, personal)
- [ ] Be optimized for target engagement signals
- [ ] Include visual media when possible (image/video)
- [ ] Be posted during golden window (9-10 AM, 1-2 PM, 6-7 PM)
- [ ] Respect author diversity limit (max 3 posts/day)
