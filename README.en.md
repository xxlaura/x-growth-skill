# x-growth

**English** | [中文](README.md)

AI-powered growth hacking toolkit for X (Twitter), reverse-engineered from the [For You feed algorithm source code](https://github.com/xai-org/x-algorithm).

A skill for AI Agents (Qwen Code, Claude Code, Cursor, etc.) that generates algorithm-optimized tweets, threads, video scripts, KOL replies, giveaways, and weekly content calendars through 13 sub-commands.

## Why This Exists

The X For You algorithm is [open source](https://github.com/xai-org/x-algorithm). We extracted every ranking signal, weight formula, and content filter from the source code. This skill turns those algorithm secrets into actionable content generation rules:

- **19 engagement signal weights** — DM Share > Reply > Like > Repost
- **80-hour post lifespan** — first 2 hours are the golden ignition period
- **Author diversity penalty** — max 3 posts/day or the algorithm suppresses you
- **Slop Score** — AI-generated content detection requires specific anti-detection strategies
- **VQV video signal** — 30s-2min videos trigger multiple high-weight signals

## Quick Start

### Installation

**Option 1: Direct copy**

```bash
# Clone the repo
git clone https://github.com/xxlaura/x-growth-skill.git

# Copy to your project's skills directory
cp -r x-growth-skill .agents/skills/x-growth
```

**Option 2: Git Submodule**

```bash
git submodule add https://github.com/xxlaura/x-growth-skill.git .agents/skills/x-growth
```

**Option 3: Manual download**

Download this repository and place the files in your project's `.agents/skills/x-growth/` directory.

### Step 1: Set Up Your Voice

```
/x-growth voice-setup
```

A 3-batch interview + writing sample analysis generates your account voice profile:

- `config/about.md` — account identity (who you are, who you write for)
- `config/voice.md` — voice rules (how you sound + what you never say)

All subsequent commands automatically read these files to ensure consistent style.

**4 quick presets (skip the interview):**

| Preset | Style | Reference Accounts |
|--------|-------|--------------------|
| A) Product-Led Brand | Crisp, product speaks for itself | @linear, @stripe |
| B) Developer Builder | Technical + playful + opinionated | @supabase, @railway |
| C) Technical Educator | Clear, depth-first, generous | @swyx, @karpathy |
| D) Founder Voice | Bold, visionary, transparent | Building in public style |

## Commands

### Daily Commands (memorize these 5)

| Command | Purpose | Example |
|---------|---------|---------|
| `write` | Write a single tweet | `/x-growth write Qwen3.7 multimodal` |
| `rewrite` | Remove AI-sounding language | `/x-growth rewrite [paste text]` |
| `reply` | Write a KOL reply | `/x-growth reply [KOL's post]` |
| `hook` | Generate opening hooks | `/x-growth hook API price drop` |
| `audit` | Pre-publish quality check | `/x-growth audit [your post]` |

### Advanced Commands

| Command | Purpose |
|---------|---------|
| `voice-setup` | Set up / update account voice |
| `thread` | Write a thread (5-12 tweets) |
| `video-script` | Write a video script (30s-2min) |
| `giveaway` | Design an algorithm-friendly giveaway |
| `calendar` | Generate a weekly content calendar |
| `benchmark` | Write a comparison/benchmark post |
| `meme` | Write an industry meme |
| `analyze` | Analyze post performance data |

### Natural Language (no command names needed)

```
/x-growth help me write a tweet about video understanding    → write
/x-growth this sounds too AI, rewrite it: [paste]            → rewrite
/x-growth this person posted this, help me reply: [paste]    → reply
```

The system auto-detects your intent.

## Account Types & Anti-Slop Strategies

Different account types require fundamentally different anti-AI-detection approaches:

| Type | Anti-Slop Method | Best For |
|------|-----------------|----------|
| **Personal** | Casual tone + imperfection + emoji + personal stories | Founders, developers, creators |
| **Brand** | Specific numbers + insider data + technical precision + restraint | Companies, products, teams |
| **Hybrid** | Mix of both | CEO representing a brand, team leads |

`voice-setup` automatically applies the right strategy based on your account type.

├── reference/

│   ├── algorithm.md            # X algorithm core knowledge

│   ├── content-types.md        # 8 content type templates
│   ├── hooks.md                # 10 opening hook formulas
│   ├── cta-patterns.md         # CTA trigger templates
│   ├── thread-structure.md     # Thread structure templates
│   ├── video-script.md         # VQV-optimized video scripts
│   ├── reply-craft.md          # High-quality KOL reply writing
│   ├── giveaway-design.md      # Algorithm-friendly giveaway design
│   ├── cadence.md              # Posting cadence & time windows
│   └── weekly-calendar.md      # 4-week content calendar templates

### Dependency Chain

```
voice-setup → about.md + voice.md
                    ↓
          All downstream commands read
    (write, thread, reply, hook, rewrite...)
```

`voice-setup` is the foundation. Every other command reads `config/about.md` and `config/voice.md` before generating content.

## Key Algorithm Numbers

| Parameter | Value |
|-----------|-------|
| Post max lifespan | 80 hours (3.3 days) |
| Golden ignition period | First 2 hours |
| Max posts per day | 3 (more = algorithmic penalty) |
| Min gap between posts | 4 hours |
| Engagement signal ranking | DM Share > Reply > Like > Repost |
| Optimal video duration | 30s - 2min |
| 2nd post from same author | 55% score |
| 3rd post from same author | 32.5% score |
